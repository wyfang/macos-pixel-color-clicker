# 屏幕颜色触发点击器（macOS / Windows 11）

一个轻量的原生屏幕颜色自动点击工具，提供 macOS 和 Windows 11 版本。它持续读取用户指定位置的屏幕颜色，在颜色匹配或区域颜色发生变化时执行鼠标左键点击。

程序使用 Swift、AppKit 和 CoreGraphics 编写，不依赖第三方运行库，也不会连接网络或上传屏幕内容。

## 功能

- 移动鼠标后按 `Enter` 确认监控位置。
- 两种监控模式：
  - 匹配一个或多个目标颜色。
  - 检测监控区域的颜色变化，采样区域支持 `1×1` 至 `10×10`。
- 支持 `#RRGGBB` 十六进制颜色。
- 可直接从屏幕吸取颜色。
- 每个目标颜色可独立设置点击延时、连续点击次数和点击间隔。
- 像素变化模式也可设置点击延时、连续点击次数和点击间隔。
- 点击次数默认为 1 次，可设置 1–100 次；延时及间隔范围为 0–60000 毫秒。
- RGB 三个通道支持 0–100 的可调颜色容差。
- 点击位置可选择：
  - 已选择的监控位置。
  - 触发瞬间的当前鼠标位置。
- 开始监控前有倒计时；macOS 为 3 秒，Windows 11 可设置为 0–60 秒并默认 3 秒。
- 全局 `Esc` 紧急停止，另有高频物理按键检测作为备用停止通道。
- 颜色持续保持匹配时只点击一次，离开并再次进入目标范围后才会再次触发。

## 系统要求

- macOS 13 或更高版本。
- Apple Command Line Tools，用于从源码构建。
- 当前构建脚本会为正在使用的 Mac 架构生成应用。

## 使用方法

1. 启动应用。
2. 点击“选择位置”，将鼠标移动到需要监控的像素，然后按 `Enter`。
3. 选择“匹配目标颜色”或“检测像素变化”。
4. 如果使用目标颜色模式：
   - 输入颜色值，例如 `#66D169`；或点击“吸取”，移动鼠标后按 `Enter`。
   - 点击“添加颜色”可增加更多目标。
   - 为每种颜色设置独立的延时、点击次数和点击间隔。
5. 如果使用像素变化模式，选择采样区域大小，并设置延时、点击次数和点击间隔。
6. 设置颜色容差和点击位置。
7. 点击“开始监控”。3 秒倒计时结束后正式开始。
8. 随时按 `Esc` 停止，尚未执行的延时点击和连续点击会立即取消。

目标颜色列表至少保留一项。如果设置了延时，目标颜色需要在延时期间持续匹配；颜色消失、切换或按下 `Esc` 都会取消尚未执行的点击。

## 权限

首次使用时，macOS 会要求以下权限：

- **屏幕录制**：仅用于读取所选位置的像素颜色。
- **辅助功能**：用于模拟鼠标左键点击和监听全局停止按键。

请在“系统设置 → 隐私与安全性”中授权。授权后如果没有立即生效，请完全退出并重新打开应用。

## 从源码构建

项目只需要 Apple Command Line Tools，不需要完整 Xcode：

```bash
chmod +x build_app.sh
./build_app.sh
```

构建完成后会生成：

```text
outputs/像素变化点击器.app
```

## Windows 11 版本

Windows 11 版本位于 [`Windows11`](Windows11) 目录。GitHub Actions 会使用 Windows 构建机生成自包含的单文件 `PixelColorClicker.exe`；可在仓库的 **Actions → Build Windows EXE** 页面下载成功构建的产物。

Windows 11 版本还支持醒目的管理员权限状态及一键 UAC 重启、`F6`–`F12` 可选全局启动快捷键、0–60 秒启动倒计时，并会在退出时保存监控位置、目标颜色列表以及两种模式的全部参数。

## 触发规则

### 目标颜色模式

容差按 RGB 每个通道分别计算。例如目标颜色为 `#66D169`、容差为 10，则 R、G、B 三个通道允许各自相差 ±10。多个颜色范围重叠时，列表中靠前的颜色优先。

### 像素变化模式

倒计时结束时记录采样区域的平均颜色。当任一 RGB 通道的变化超过容差时，按设置的延时、次数和间隔执行点击；随后等待颜色稳定 250 毫秒，再继续检测下一次变化。`1×1` 为单像素，较大的区域可减少单个像素抖动造成的误触发。

## 注意事项

请只在你有权自动化操作的软件和场景中使用本工具。部分游戏、网站或服务可能禁止自动点击，请遵守相应规则。
