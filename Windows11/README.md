# Windows 11 版本

本目录用于存放屏幕颜色触发点击器的 Windows 11 版本。

计划采用 C#、.NET 和 Windows Forms 实现，并通过 GitHub Actions 的 Windows 构建环境生成自包含的 `win-x64.exe`。

Windows 版本将保持与 macOS 版本一致的核心功能：

- 选择并监控屏幕像素位置。
- 匹配一个或多个目标颜色。
- 屏幕取色、颜色容差和独立点击延时。
- 检测像素颜色变化。
- 点击监控位置或当前鼠标位置。
- 3 秒启动倒计时。
- 全局紧急停止。

后续 Windows 项目源码、构建脚本和相关文档将放在此目录中。
