# macOS 屏幕颜色触发点击器

一个轻量的原生 macOS 自动点击工具。它持续读取用户指定位置的屏幕像素，在颜色匹配或像素发生变化时执行一次鼠标左键点击。

程序使用 Swift、AppKit 和 CoreGraphics 编写，不依赖第三方运行库，也不会连接网络或上传屏幕内容。

## 功能

- 移动鼠标后按 `Enter` 确认监控位置。
- 两种监控模式：
  - 匹配一个或多个目标颜色。
  - 检测监控像素的颜色变化。
- 支持 `#RRGGBB` 十六进制颜色。
- 可直接从屏幕吸取颜色。
- 每个目标颜色可设置独立点击延时，范围为 0–60000 毫秒。
- RGB 三个通道支持 0–100 的可调颜色容差。
- 点击位置可选择：
  - 已选择的监控位置。
  - 触发瞬间的当前鼠标位置。
- 开始监控前有 3 秒倒计时。
- 全局 `Esc` 紧急停止，另有高频物理按键检测作为备用停止通道。
- 颜色持续保持匹配时只点击一次，离开并再次进入目标范围后才会再次触发。

## 系统要求

- macOS 13 或更高版本。
- Apple Command Line Tools，用于从源码构建。
- 当前构建脚本会为正在使用的 Mac 架构生成应用。

## 使用方法

1. 启动应用。
2. 点击“选择位置”，将鼠标移动到需要监控的像素，然后按 `Enter`。
3. 选择“匹配目标颜色”或“检测像素变化”。
4. 如果使用目标颜色模式：
   - 输入颜色值，例如 `#66D169`；或点击“吸取”，移动鼠标后按 `Enter`。
   - 点击“添加颜色”可增加更多目标。
   - 为每种颜色填写独立延时，单位为毫秒。
5. 设置颜色容差和点击位置。
6. 点击“开始监控”。3 秒倒计时结束后正式开始。
7. 随时按 `Esc` 停止。

目标颜色列表至少保留一项。如果设置了延时，目标颜色需要在延时期间持续匹配；颜色消失、切换或按下 `Esc` 都会取消尚未执行的点击。

## 权限

首次使用时，macOS 会要求以下权限：

- **屏幕录制**：仅用于读取所选位置的像素颜色。
- **辅助功能**：用于模拟鼠标左键点击和监听全局停止按键。

请在“系统设置 → 隐私与安全性”中授权。授权后如果没有立即生效，请完全退出并重新打开应用。

## 触发规则

### 目标颜色模式

容差按 RGB 每个通道分别计算。例如目标颜色为 `#66D169`、容差为 10，则 R、G、B 三个通道允许各自相差 ±10。多个颜色范围重叠时，列表中靠前的颜色优先。

### 像素变化模式

倒计时结束时记录基准颜色。当任一 RGB 通道的变化超过容差时点击一次，随后等待颜色稳定 250 毫秒，再继续检测下一次变化。

## 注意事项

请只在你有权自动化操作的软件和场景中使用本工具。部分游戏、网站或服务可能禁止自动点击，请遵守相应规则。
